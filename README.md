# Переводчик конфигураций в JSON · Вариант №6

## 1. Общее описание

Программа читает файл на учебном конфигурационном языке, разбирает его
по грамматике Lark и печатает итоговое значение в формате JSON.
Например, конфигурация `global n = +02 [${n}; -1]` даёт `[2, -1]`.

## 2. Функции и настройки

Документ состоит из нуля или нескольких объявлений констант и одного
итогового значения. Таким значением может быть число, массив или ссылка
на ранее объявленную константу. Пробелы, табуляция и переводы строк
между элементами синтаксиса пропускаются.

- **Целое число** записывается по шаблону `[+-]?\d+`. Знак необязателен.
  При выводе в JSON ведущие нули и знак `+` исчезают.
- **Массив** записывается в квадратных скобках. Элементы разделяются
  точкой с запятой. Допускаются пустые и вложенные массивы, например
  `[[]; [1; -2]]`. После последнего элемента разделитель не ставится.
- **Константа** объявляется как `global имя = значение`. Имя соответствует
  шаблону `[_a-zA-Z][_a-zA-Z0-9]*`. Регистр букв имеет значение.
  При повторном объявлении одного имени программа сообщает об ошибке.
- **Ссылка** `${имя}` подставляет значение константы, в том числе внутри
  массива или в правой части следующего объявления. Область действия
  константы заканчивается вместе с документом.
- **Комментарии** начинаются с отдельного слова `REM` и продолжаются
  до конца строки либо заключаются между `#=` и ближайшим `=#`.
  В позиции имени перед `=` или `}` слово `REM` обозначает константу.
  Например, `global REM = 2 ${REM}` даёт `2`.

Ключ `--input ПУТЬ` обязателен. Файл читается в UTF-8, допускается BOM.
Путь с пробелами заключайте в двойные кавычки. Ключ `--help` выводит справку.

При успехе программа пишет JSON в стандартный вывод и возвращает код 0.
При ошибке в файле она пишет сообщение в стандартный поток ошибок
и возвращает код 1. Для ошибок синтаксиса и имён указываются строка
и столбец. Ошибка в аргументах командной строки даёт код 2.

## 3. Сборка и запуск тестов

Понадобится Python 3.11 или новее с командой `py` для Windows.
Откройте командную строку Windows (`cmd.exe`) в корне клонированного
репозитория. Проект запускается из исходников. Создайте виртуальное
окружение, активируйте его и установите зависимость из файла проекта.

```bat
py -3 -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
```

В том же окне запустите тесты грамматики и командной строки.

```bat
python -m unittest discover -s tests -v
```

При открытии нового окна снова активируйте окружение из корня проекта.

## 4. Примеры использования

**Метеонаблюдения.** Каждая пара содержит утреннюю и вечернюю температуры
за один день. Отрицательные значения обозначают температуру ниже нуля.

```bat
run.bat --input examples\weather.cfg
```

```json
[[-4, 2], [-1, 5]]
```

**Музыкальный ритм.** Константа `beat` задаёт длительность короткой ноты
в долях такта. Константа `bar` собирает три длительности в такт.
Итоговый массив повторяет этот такт дважды.

```bat
run.bat --input examples\music.cfg
```

```json
[[1, 1, 2], [1, 1, 2]]
```
